# 🍽️ Reestar

Reestar is a **simple and elegant restaurant recipe website** created using **HTML & CSS**.  
It features a clean layout, a recipes gallery, and a contact form for users to get in touch.

---

## 🚀 Features

- 🧭 **Navigation Bar** — Smooth and simple navigation to Home, Recipes, and Contact sections.  
- 🍜 **Recipes Section** — Attractive cards with images, titles, and order buttons.  
- 📞 **Contact Form** — Clean form design with name, age, and email fields.  
- 🎨 **Modern UI** — Responsive, minimal, and easy to customize.

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (External stylesheet)
